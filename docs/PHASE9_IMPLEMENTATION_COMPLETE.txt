================================================================================
KEY DESIGN DECISIONS
================================================================================

1. FP32 Intermediates Throughout
   - All three kernels (QK, Softmax, AV) accumulate in FP32
   - Preserves numerical precision vs. lower-precision accumulators
   - Matches checkpoint PyTorch semantics

2. Low-Precision at Model Boundaries
   - Input tensors: BF16 or FP16
   - Output tensors: same as input
   - Conversion uses Phase 8.2-style rounding

3. Per-Request Cache Allocation
   - Explicit ownership via Workspace slots
   - Separate cache for each request
   - No implicit sharing or fallback

4. Explicit Synchronization
   - Queue sync required between QK→Softmax→AV stages
   - No automatic backend retry
   - Dispatch methods currently stubs; require BANG C implementation

5. Frozen Phase 8.2 Components
   - No modifications to accepted kernels
   - Eliminates regression risk
   - Simplifies debugging
